# Maya Di Pietro — Portfolio

Site statique (HTML / CSS / JS), trilingue EN / FR / IT.
Typographie : Polymath (Adobe Fonts, kit `jyc0jgu`).

- `index.html` : la page
- `css/style.css` : le style
- `js/main.js` : les animations et interactions
- `js/content.js` : tous les textes (EN / FR / IT)
- `assets/img/` : les images

Publication : GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
Pour que la typo Polymath s'affiche, ajoute le domaine du site (`<ton-nom>.github.io`) dans ton projet web Adobe Fonts.
